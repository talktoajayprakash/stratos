# Security policy

## Report a vulnerability

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/talktoajayprakash/stratos/security/advisories/new).
Please do not disclose vulnerabilities in public issues or pull requests.

Include the affected Stratos version or commit, reproduction steps, expected
and observed behavior, and the potential impact. For harness or MCP issues,
include the relevant harness, provider, and server versions.

Use a minimal reproduction with synthetic data. Remove credentials, tokens,
personal data, and private workflow content from logs and traces before sharing.
